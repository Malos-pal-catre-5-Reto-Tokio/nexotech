# NexoTech — Tienda Online
Desarrollo Fullstack II.
Tienda online de tecnología desarrollada con HTML, CSS3 y JavaScript.

## Integrantes
- Martin
- Eidan

## Estructura del proyecto
- `/tienda` — vistas públicas (home, productos, login, registro, carrito, etc.)
- `/admin` — panel administrador (gestión de productos y usuarios)
- `/css` — hojas de estilo
- `/js` — lógica y validaciones
- `/img` — recursos gráficos

## Roles del sistema
- **Administrador**: acceso total al sistema.
- **Vendedor**: visualiza productos y órdenes.
- **Cliente**: acceso solo a la tienda.
